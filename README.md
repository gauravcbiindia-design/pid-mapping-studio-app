# P&ID Mapping Studio — browser release

This is a public no-login browser build. It stores imported PDFs and workspace records in the current browser profile only; different devices and profiles do not share data. It does not include company CAD files or a central library, and native DWG conversion is not provided in this release. The published site serves compiled assets only; browser JavaScript can be inspected. Do not upload confidential drawings unless your organization has approved this hosting arrangement.
